<h1>Rock Paper Scissor Game 🎮</h1> 🎮

A browser-based Rock Paper Scissor game built using HTML, CSS, and JavaScript.

🚀 Features

🪨 Rock, 📄 Paper, and ✂️ Scissor are the  choices
Computer have and it randomly selects a choice
and displays the result of each round
Keeps track of the score in result buttons.

🛠️ Technologies Used

HTML
CSS
JavaScript

🎮 How to Play 
<br>

Choose Rock, Paper, or Scissor.
The computer randomly selects one of the three options.
<br>

The winner is determined using the standard rules:
<br>

Rock beats Scissor
<br>
Scissor beats Paper
<br>
Paper beats Rock
<br>

The score is then updated after each round.
<br>
